# archive — historical design & planning docs

These are the early design, planning, and notes documents that guided XyScript's
development (the interpreter plan, the byte-text engine plan, the keyboard-layer
design, feature notes, and so on). They are kept for history and rationale, not as
current documentation — for that, see `docs/` (the user manual and command
reference) and the per-crate `README`s.

Much of the source still cites these by **bare filename** in its module/doc
comments (for example ``development-plan.md Stage 2`` or
``stage1-interpreter-plan.md §6``). Those citations name the document, not a path,
so they continue to resolve to the files now living here.
